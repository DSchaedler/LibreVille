# LibreVille

LibreVille is a city building simulation game inspired by SimCity, Cities: Skylines and countless others. LibreVille is written in [mruby](https://mruby.org/) in the [DragonRuby Game Toolkit](https://dragonruby.org/). You can obtain a copy of the engine at https://dragonruby.org/#purchase. The source code for LibreVille can be obtained at https://github.com/DSchaedler/LibreVille.

## Wait, that's not open source.

TLDR: LibreVille is [Shareware](https://en.wikipedia.org/wiki/Shareware).

There are 2 reasons why LibreVille isn't open source (yet):
1. [DragonRuby GTK is not open source](https://docs.dragonruby.org/#/misc/faq?id=dragonruby-is-not-open-source-thats-not-right). While I intend my code to be open source, I'm not sure how the licensing applies to their material.
2. I don't want clones ripping off my customers.

So, for legal reasons, LibreVille is Copyrighted material. If an actual laywer wants to write a better license for me, please contact me.
